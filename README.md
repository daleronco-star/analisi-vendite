\# Analisi vendite — Python e Power BI



\## Descrizione

Progetto di analisi dati sulle vendite con Python e Power BI, realizzato su un dataset simulato a scopo didattico.



\## Strumenti utilizzati

\- Python

\- Pandas

\- Matplotlib

\- Power BI



\## Obiettivi

\- Calcolare i ricavi totali.

\- Analizzare i ricavi per prodotto.

\- Confrontare le quantità vendute.

\- Visualizzare i risultati tramite grafici e dashboard.



\## Risultati principali

\- \*\*Ricavi totali:\*\* 3.525 €

\- \*\*Prodotto con maggiori ricavi:\*\* Laptop — 2.400 €

\- \*\*Prodotto con più unità vendute:\*\* Mouse — 18 unità



\## Struttura del progetto

\- `data/`: dataset CSV.

\- `images/`: grafico dei ricavi per prodotto.

\- `notebooks/`: notebook Python.

\- `dashboard\_vendite.pbix`: report Power BI.
